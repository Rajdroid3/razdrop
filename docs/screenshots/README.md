# Razdrop Screenshots & Visual Assets

This directory contains visual assets and screenshots representing the Razdrop application across mobile and Android TV platforms.

## Directory Contents

| Asset | Description | Source / Status |
| ----- | ----------- | --------------- |
| `logo.svg` | Vector brand logo (Cyber Midnight Navy + Electric Cyan monogram) | Rendered from `ic_razdrop_logo.xml` |
| `banner.svg` | Leanback TV banner asset (`320x180 dp`) | Rendered from `tv_banner.xml` |
| `tv-home.png` | Android TV 10-foot Leanback interface (QR, PIN & Send Files from TV) | Genuine Android TV capture (1080p) |
| `tv-transfer.png` | Android TV transfer completion dashboard | Genuine Android TV capture (1080p) |

## Capture Guidelines

- All application screenshots must be genuine captures from a physical device or official Android emulator.
- No AI-generated or fabricated mockups.
- Private information (credentials, internal Wi-Fi passwords, private tokens) must be omitted or sanitized before publication.
